# 커리큘럼 검수 — 도움을 받으며 직접 구현할 수 있는가

검수일: 2026-11-02 · [현재 학습 지도](../curriculum/README.md) · [구현 명세](IMPLEMENTATION.md)

## 보강 전 판정

**구조를 이해하는 독서 경로로는 타당하다. 그러나 현재 문서만을 기준으로 GPT·검색·영상의 도움을 받아 처음부터 축소 모델을 끝까지 구현할 수 있다고 보증할 단계는 아니다. 구현 학습 안내를 보강해야 한다.**

이미 PyTorch로 모델을 학습시키고 shape·gradient·mask 오류를 스스로 추적할 수 있는 사람이라면 이 목록을 출발점으로 진행할 수 있다. 그 경험이 없다면 2주차부터 별도의 강의를 찾아 학습 경로를 다시 구성해야 할 가능성이 높다. 사용자의 현재 숙련도는 확인하지 않았으므로 개인의 완주 가능성이나 소요 기간을 단정하지 않는다.

핵심 문제는 논문 수가 적어서가 아니다. 수식에서 작은 연산으로, 작은 연산에서 모듈로, 모듈에서 학습 가능한 모델로 넘어가는 중간 단계가 부족하다. 원본 Qwen의 규모·성능 재현은 목표에서 제외하고, 사용자가 직접 쓰는 축소 구현을 기준으로 평가했다.

## 검수 범위

- 현재 16개 주차의 목표·설명·과제·검증 조건, 전체 지도, 필수 자료 목록, 목표 구조·구현 명세·검증 기록을 검토했다.
- Harvard Annotated Transformer, 목표 논문, 고정 revision의 Transformers 모델 구현, 이미지 processor 설정을 대조했다.
- GDN 보조 자료가 실제로 제공하는 내용을 재확인하고, 부족한 기초 학습에 쓸 공식 튜토리얼과 강의 저자의 강좌 페이지를 확인했다.
- 모델 코드를 작성하거나 실행하지 않았다. 축소 config 생성, CPU/GPU 호환성, 학습 성공, 수치 일치는 검증하지 않았다. 영상 전체를 시청하지 않았다.
- 이전의 내부 링크 검사는 문서 이동이 가능하다는 증거다. 독학자가 과제를 완수할 수 있다는 증거는 아니다.

## 논문 수를 늘리지 않는 보강안

필수 8편과 3개 큰 단원은 유지할 수 있다. 16주는 확정 소요 기간이 아니라 순서로 해석하는 현재 안내도 유지한다. 다만 각 단계의 통과 여부가 다음 단계 진입 기준이어야 한다.

| 중간 완료 지점 | 확인할 것 | 그다음 추가할 것 |
|---|---|---|
| A. 작은 dense text LM | loss·생성·저장/복원·causal mask | RoPE/GQA와 cache |
| B. 현대 decoder의 기본 연산 | norm·SwiGLU·head 공유·routing 단위 검사 | GDN hybrid |
| C. hybrid 텍스트 모델 | recurrent/dense 비교·문맥 분할 | GR, QSA, PLE를 각각 추가 |
| D. 작은 이미지 모델 | 시각 입력 의존성·label mask·단일 이미지 생성 | 위치·여러 이미지·영상 |
| E. 선택한 전체 구조의 축소 통합 | 구성요소 비교·hybrid cache·재실행 | 공식 전체 logits 대조와 상세 측정 |

중간 단계에서 dense attention·일반 residual·단순 projector를 쓰는 것은 학습 순서의 일부다. 목표 모델과 동일하다고 표시하지 않는다. 전체 구조를 반영하려면 이후 해당 구성요소를 추가하고 차이를 기록해야 한다.

각 주차에 필요한 최소 보강 묶음은 **수식/연산 순서 1개 + 고정 입력 예제 1개 + 예상 중간값/shape + 실패 사례 + 단계별 힌트 + 관련 자료의 읽을 위치**다. 정답 코드를 제공할 필요는 없다.

## 실제로 도움이 될 추가 자료 — 필독 논문 추가 없음

| 자료 | 용도 | 읽거나 볼 범위 |
|---|---|---|
| [PyTorch 기본 익히기 한국어 번역](https://tutorials.pytorch.kr/beginner/basics/intro.html) | 1주차 이전 부족한 부분 보충 | Tensor, Autograd, 최적화, 저장/불러오기 |
| [PyTorch 공식 Learn the Basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html) | 번역/API 차이 대조 | 위 항목의 영어 원문 |
| [Karpathy Zero to Hero](https://karpathy.ai/zero-to-hero.html) | 언어모델 학습의 연결 설명 | 부족하면 makemore, 이후 Let's build GPT |
| [Let's build GPT 영상](https://www.youtube.com/watch?v=kCc8FmEb1nY) | 2주차 decoder-only 실습 흐름 | 강의 설명을 보고 직접 작성; 처음부터 끝까지 코드 복사하지 않기 |

PyTorch 공식 튜토리얼은 tensor부터 최적화·저장까지의 학습 흐름을 제공한다. Karpathy의 강좌 페이지는 GPT 강의 전에 tensor·자기회귀 모델의 기초가 필요함을 명시한다. 이 두 가지 연결 자료가 현재 공백에 직접 대응한다. 강좌 페이지와 영상 연결은 확인했으나 영상 전체 시청 검증은 하지 않았다.

## GPT·검색·영상 도움을 받는 방법

다음과 같이 질문 범위를 제한하면 정답 코드를 넘겨받지 않고도 도움을 얻을 수 있다.

> 목표: [이번에 이해/구현할 단일 연산]. 기준 자료: [논문 절 또는 고정 코드 링크]. 입력 shape와 dtype: [...]. 내가 예상한 중간값: [...]. 실제 결과 또는 이해가 안 되는 부분: [...]. 완성 코드는 쓰지 말고, 먼저 축·수식·가정 중 잘못된 부분을 지적하고 힌트를 하나만 줘. 제안한 검사에서 기대하는 결과와 근거도 설명해 줘.

검색어에는 모델 이름만 쓰지 말고 연산과 증상을 포함한다. 예를 들어 'causal depthwise convolution state', 'RoPE KV cache position offset', 'QSA complete block tail mask'처럼 좁힌다. 다른 모델의 설명을 발견하면 target의 norm·gate·mask·position 정의와 맞는지 확인한다.

GPT가 제시한 수치나 해석은 정답으로 고정하지 않는다. 손계산, 원문, 독립된 reference 중 하나로 확인한다. 내가 쓴 코드가 구조와 맞는지 설명할 수 있는 것이 완료 기준이다.
