# 검수 지적 3~5 — 단계·검사·대조

[이전 지적](REVIEW_FINDINGS_01.md) · [검수 요약](CURRICULUM_REVIEW.md) · [다음 지적](REVIEW_FINDINGS_03.md)

당시 문서의 행 번호를 기록한 보강 전 검수 근거입니다. [현재 조치](REVIEW_RESOLUTION.md)를 함께 봅니다.

### 3. 6~8주의 난도 상승을 받쳐 줄 중간 산출물이 없다 — 높음

**근거:** [6주차](../curriculum/02-backbone/week-06/README.md) 33~35행은 목표형 GDN과 GR을 동시에 연결한다. [8주차](../curriculum/02-backbone/week-08/README.md) 33~35행은 n-gram, PLE, 8층 본체, tokenizer 구분까지 한 번에 다룬다. 두 주차 모두 해설은 같은 전체 모델 소개 글에 주로 의존한다.

**막히는 지점:** causal depthwise convolution, L2/RMS 정규화, gate 값의 범위, branch 읽기/쓰기, hash 계산, dilation이 처음 등장하는데 이를 독립적으로 연습할 과제가 부족하다. 실패하면 어느 구성요소에서 잘못됐는지 구분하기 어렵다.

**보완:** 주차를 더 잘게 폴더링할 필요는 없다. 각 주차 안에 '작은 연산 → 단일 모듈 → 기존 모델에 한 가지 변경 → 검증'의 중간 완료 지점을 넣는다. GDN 교체, GR 도입, QSA 도입, PLE 도입마다 이전 모델을 보존해 비교한다. 각각 입력 예시, 기대 shape, 손계산할 수치, 대표 실패 원인을 제공한다.

### 4. QSA의 핵심 선택 동작을 현재 예제로는 검증할 수 없다 — 높음

**근거:** [7주차](../curriculum/02-backbone/week-07/README.md) 29행의 예제는 r=4, K=8, 보이는 token 11개다. 완성 block이 2개여서 예산 안에 모두 들어간다. [구현 명세](IMPLEMENTATION.md) 33행의 기본 K=16과 94행의 길이 1~9 경계 검사도 token을 제외하는 상황을 만들지 않는다.

**영향:** tail·경계 검사는 가능하지만 '잘못된 top-k 또는 모든 block 선택'을 놓칠 수 있다. budget이 충분할 때 dense attention과 같아야 한다는 검사만으로 sparse selection이 맞다고 판단할 수 없다.

**보완 예시:** 선택 단계의 단위 문제에서 r=4, K=4, 길이 11, 완성 block 점수 [0.1, 0.9]를 지정한다. 기대 선택 token 집합은 {4,5,6,7,8,9,10}, 제외는 {0,1,2,3}이다. 점수 순서를 반대로 바꾸면 선택 block도 달라져야 한다. 이 문제는 pooling/RoPE/score 계산 검사를 대체하지 않으며, 해당 단계들은 별도 고정 입력으로 검증해야 한다.

### 5. 공식 구현과 결과를 비교하라는 요구에 비해 비교 환경·절차가 부족하다 — 높음

**근거:** [구현 명세](IMPLEMENTATION.md) 23행은 축소 config가 미실행 설계안임을 밝힌다. 82행부터 동일 작은 config·가중치 비교를 요구하고, [6주차](../curriculum/02-backbone/week-06/README.md)부터 이 결과가 완료 기준에 들어간다.

**막히는 지점:** 고정 코드 링크는 있지만 사용할 Python/PyTorch/Transformers 환경, 작은 reference 생성 절차, parameter 대응표, 자동 초기화 차이, 지원 backend를 확인하는 순서가 없다. 같은 seed만 주는 것으로 구조가 다른 두 구현의 가중치가 같아지지는 않는다. 설치 실패와 수식 오류를 구별하기도 어렵다.

**보완:** 정답 구현을 대신 쓰지 않고도 환경 준비표, parameter 이름/shape 대응 예시, 고정 입력과 비교 위치, 오차 기록 양식을 제공할 수 있다. 먼저 손계산과 연산 불변성을 검사하고 공식 단일 모듈 비교로 진행한다. 전체 logits 일치는 심화 완료 단계로 둔다. 현재 설정이 실제로 실패한다고 판정한 것은 아니며, 실행 가능성이 아직 입증되지 않았다는 지적이다.
