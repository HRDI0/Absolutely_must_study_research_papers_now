# 최종 프로젝트 · 구조를 설명하는 비교 보고서

[12주차 계획](../curriculum/week-12/README.md) · [보고서 작성](REPORT.md)

## 목표

**DeepSeek-V3, Qwen3.8-Next, Qwen3-VL**을 비교하며 attention·FFN·입력 연결·학습 방법을 구분합니다. 세 모델은 목적이 다르므로 벤치마크 점수 하나로 순위를 매기지 않습니다.

## 작성할 결과물

1. 모델별 블록 그림 1장씩: 입력부터 출력까지 모듈을 표시
2. 공통 비교표: attention, state/KV cache, FFN/MoE, position, modality connector, 학습 목표
3. 비용 비교: 줄어드는 비용과 남는 비용, prefill/decode 구분
4. 원문 실험 2개 이상: 결과와 조건, 해석 가능한 범위
5. 10분 발표 개요와 예상 질문 5개

## 완료 기준

| 기준 | 확인 질문 |
|---|---|
| 구조 | 각 모듈의 입력·출력과 역할을 설명할 수 있는가? |
| 비용 | FLOPs·캐시 저장량·메모리 이동·실제 지연을 구분했는가? |
| VLM | 이미지/영상이 LLM 입력과 내부 층으로 전달되는 흐름을 그렸는가? |
| 근거 | 주장과 수치에 원문 절·표·그림·실험 조건을 기록했는가? |
| 한계 | 비교 대상의 목적·모델 변형·측정 조건 차이를 밝혔는가? |

5개 기준을 모두 만족하면 기본 과정을 완료합니다. 실험 재현은 선택이며, 수행하지 않은 성능 결과를 직접 측정한 것으로 적지 않습니다.
